<h1 align="left">Google Review Cluster</h1>

###

<p align="left">A simple Streamlit app for analyzing and visualizing user clusters from Google Reviews rating data. This project attempts to find different user archetypes based on the places they review and the ratings they give.</p>

###

<h3 align="left">About the Project</h3>

###

<p align="left">What's This Project About? Ever have a ton of rating data but no idea what patterns are hidden inside? This app helps turn that raw data into understandable insights. Using the K-Means algorithm, we can automatically group users with similar tastes.<br><br>The result is an interactive application where we can:<br>- Experiment with clustering parameters.<br>- See the grouping results visually.<br>- Analyze the characteristics of each user group.</p>

###

<h3 align="left">Features</h3>

###

<p align="left">- Interactive Configuration: Directly experiment with the number of clusters (K) and the data scaling method via the sidebar.<br>- Result Visualization: See the clustering results in an interactive 2D plot (you can choose between PCA or LDA).<br>- Evaluation Metrics: Check how good the model is with metrics like the Silhouette Score.<br>- Download Data: Download the final results with cluster labels as a CSV file.</p>

###

<h3 align="left">Tech Stack</h3>

###

<p align="left">- Backend & Machine Learning: Python, Scikit-learn, Pandas, NumPy<br>- Frontend / UI: Streamlit<br>- Visualization: Matplotlib & Seaborn</p>
